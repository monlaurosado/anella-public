# Public source release

This repository is a clean-history copy of the reviewed application source, published on 2026-10-13. The original development history remains private to avoid publishing personal commit email addresses and old operational metadata.

Use the example environment files to configure your own installation. Production credentials, database records, user uploads, deployment secrets, local logs and generated builds are not included.

Dependency security checks and regression tests are documented in `security/DEPENDENCIES.md`. Run the documented checks before deploying your installation. Publishing source does not grant access to the original production services.
